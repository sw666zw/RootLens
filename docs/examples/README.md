# Curated example artifacts

These tracked files are synthetic documentation examples, not live runtime
output. IDs, timestamps, correlation values, evidence, and measurements were
curated from test-fixture shapes. They contain no credentials, private paths,
raw telemetry responses, provider response IDs, or real OpenAI output.

- `incident-report.example.json` preserves the scenario-runner incident schema.
- `diagnosis-report.example.json` preserves the deterministic diagnosis schema.
- `template-explanation-report.example.json` preserves the offline template
  explanation schema and cites the curated diagnosis evidence.
- `benchmark-summary.example.json` preserves the benchmark report schema.
